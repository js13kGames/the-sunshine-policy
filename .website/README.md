A short point-and-click adventure about unicorns, rainbows, and a perfectly reasonable royal request in 13 kilobytes for js13kGames 2026. The theme was "Unicorns and Rainbows".

Nell, junior weather keeper, is sent to fetch the last unicorn's horn. The fields are dying, the rain mill has stopped, and the minister has excellent weather. Something doesn't add up.
